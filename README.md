# Tic-Tac-Toe

I made this little Tic-Tac-Toe game to brush up on some of my concepts.

## How It Works

The game has a **3×3 grid** where two players take turns placing `X` and `O`.

After every move, JavaScript checks the board against the **8 possible winning combinations** — 3 rows, 3 columns, and 2 diagonals.

If a player gets three of their symbols in a row, they win. If all the cells are filled without a winner, it's a draw.

This project helped me practice **DOM manipulation, event handling, JavaScript functions, arrays, and basic game logic**.
